
# Forbidden Floor — Chapter 1: Penghuni Terakhir

Game horor 2D survival story-driven untuk Android browser.
Dibuat dengan HTML5 + CSS3 + JavaScript vanilla + Canvas + Web Audio API.

## Cara Menjalankan

Buka `index.html` di browser HP Android.

## Cara Upload ke GitHub Pages

1. Buka **github.com** di browser HP → Sign in / Sign up.
2. Ketuk **+** → **New repository**.
3. Nama: `lantai-terlarang`. Pilih **Public**. Centang **Add a README file**. → **Create repository**.
4. Di repo, ketuk **Add file** → **Create new file** → nama `index.html` → tempel kode lengkap → **Commit changes**.
5. Ketuk **Settings** → **Pages** (sidebar) → **Source: Deploy from a branch** → **Branch: main / (root)** → **Save**.
6. Tunggu 1–2 menit. URL: `https://USERNAME.github.io/lantai-terlarang/`

## Ganti Foto

1. Buat folder `assets/images/` di repo (Add file → Create new file → ketik `assets/images/foto_pemain.jpg` — GitHub akan otomatis buat folder).
2. Upload `foto_pemain.jpg` dan `foto_misterius.jpg`.
3. Foto otomatis muncul di loading screen.

## Ganti Nama Pembuat

Edit `index.html` → cari `[NAMA PEMBUAT]` → ganti dengan nama kamu (3 tempat).

## Kontrol

- **Analog kiri bawah** — gerak
- **A** — interaksi
- **🔦** — senter (baterai terbatas)
- **🎒** — inventaris
- **🗺** — peta
- **⏸** — pause
- **Keyboard (opsional)**: WASD / Arrow keys

## Kode Puzzle (SPOILER!)

- **Kode Lobi**: 1107 (jam dinding)
- **Kode Arsip**: 438 (urut tahun terbaru)
- **Urutan Panel Listrik**: □ △ ⬡ ●
- **Kode Ruangan Tersembunyi**: 1549

## Alur Chapter 1

1. Loading screen → tap
2. Menu utama → MULAI
3. Intro komik 8 panel → SKIP untuk lewati
4. Eksplorasi halaman → lobi → koridor → kamar → keamanan → gudang
5. Kumpulkan 3 dokumen (A, B, C) → buka kotak arsip
6. Aktifkan panel listrik
7. Buka pintu tersembunyi → masuk → MEJA RITUAL → ending

## Jumpscare

6 jumpscare tersebar:
1. Bayangan di koridor (setelah pintu lobi)
2. Wajah di kamar 101
3. Radio tua (behind)
4. Pintu gudang
5. (cadangan: CCTV / ruang keamanan whisper)
6. Jumpscare final saat ending

## Audio

Semua audio **prosedural** via Web Audio API. Tidak butuh file mp3.
